# GOV.UK One Login — journey reference (documentation only)

This folder contains **only this README**. No GOV.UK One Login prototype HTML, layouts, notifications or authentication code are included in the public resource collection.

The [pages index](../../pages-index/README.md) retains an **illustrative historical outline** of account creation, sign-in, security-code, password-recovery and account-management journeys. Those items use `href="#"` placeholders. They are **not live links**, a usable One Login prototype, or an accurate record of the current service. Update the structure against current official guidance before using it in research.

## Authoritative resources

- [Official sign-in user journey maps](https://www.sign-in.service.gov.uk/documentation/user-journeys) — publicly documented journeys and links to further design information.
- [GOV.UK One Login HTML prototype and how to request access](https://www.sign-in.service.gov.uk/documentation/end-to-end-prototype/identity-journeys) — access-controlled, maintained by the One Login team. Eligible government service teams can request access.
- [Get started with GOV.UK One Login](https://www.sign-in.service.gov.uk/getting-started) — eligibility and integration information for service teams.

Access to the official prototype does **not** automatically grant permission to copy or republish its screens in a public repository. The historical copies previously used to inform this example have deliberately been omitted. Do not treat this collection as official GOV.UK One Login design guidance or authentication implementation.
