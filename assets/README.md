# Assets

Optional third-party resources live under `open-source/`. They are not automatically installed by templates; copy only those relevant to your prototype, review their original licences and test them in your target GOV.UK Prototype Kit.

- [Font Awesome 4.7.0](open-source/font-awesome-4.7.0/README.md) — **CSS, LESS, Sass and webfont files are bundled** for legacy icon use, with licence notices. The pages index uses its email/SMS/letter icons.
- [jQuery accessible modal window](open-source/jquery-accessible-modal-window-aria/README.md) — optional modified legacy modal script. Requires jQuery and Sass styles.

The repository's root MIT licence does not override these dependencies' separate licences or any rights held by third parties.
